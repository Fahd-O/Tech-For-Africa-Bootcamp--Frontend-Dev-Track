# Tech for Africa Bootcamp (Frontend Development Track) Project

This repository contains my submission for the **Tech for Africa Bootcamp (Frontend Development Track)**, which I attended **January 2024**. The program was organized by **Tech4Dev**, an NGO dedicated to advancing digital literacy and technology adoption across Africa. This Bootcamp provided participants with hands-on training in **HTML5** and **CSS3**, enabling us to build real-world projects based on professional design tools like **Figma**.

## About the Project

The individual task assigned during the Bootcamp was to **recreate the frontend of a static desktop (non-responsive) website** from a Figma design file using only **HTML5** and **CSS3**. The project served as an opportunity to:

- Apply foundational knowledge of web development principles.
- Enhance attention to detail by replicating a professional-grade UI.
- Develop efficient and maintainable HTML and CSS code.

This static project was developed for **desktop screens** and does not include responsiveness or JavaScript functionality.

## Key Features

- **Static Design:** Built to replicate the provided Figma file accurately for desktop viewports.
- **HTML5 Semantics:** Utilized semantic HTML tags to improve structure and accessibility.
- **CSS3 Styling:** Implemented modern styling techniques, including:
  - Custom fonts and typography.
  - Proper use of box models for layout alignment.
  - CSS grid and flexbox for structured layouts.

## Tech Stack

- **Languages:** HTML5 and CSS3
- **Tools Used:** Visual Studio Code, Git, Figma (for design reference)
- **Version Control:** GitHub

## How to View the Project

To view the project:

1. Clone the repository to your local system:

   ```bash
   git clone https://github.com/Fahd-O/Tech-For-Africa-Bootcamp--Frontend-Dev-Track.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Tech-For-Africa-Bootcamp--Frontend-Dev-Track.git
   ```

3. Open `index.html` in your preferred browser.

4. View it directly via GitHub pages [here](https://fahd-o.github.io/Tech-For-Africa-Bootcamp--Frontend-Dev-Track/)
